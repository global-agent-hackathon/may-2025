# Overview

**Microsite Generator** is an AI-driven solution that transforms raw product demo recordings into personalized, interactive microsites. By automating transcription, intelligent data extraction, and HTML generation, it streamlines sales follow-ups and enhances prospect engagement.

In today's fast-paced sales environment, following up after product demos can be time-consuming and inconsistent. Sales teams often struggle to provide personalized content that resonates with each prospect. Microsite Generator addresses this challenge by converting demo recordings into tailored microsites, ensuring a consistent and engaging follow-up experience.

# Project Objective

Our objective is to automate and personalize the post-product demo follow-up process by developing an intelligent AI agent that transforms raw demo recordings into dynamic, interactive microsites. We aim to significantly reduce manual effort for sales teams, enhance prospect engagement, and accelerate the sales cycle through intelligent content generation and seamless delivery.

# How It Works

### 🎙️ Step 1: Upload Demo Recording

Users begin by uploading a product demo recording. The system supports various audio and video formats.

### 📝 Step 2: Automated Transcription

The uploaded recording is transcribed using advanced speech-to-text algorithms, ensuring accurate and timely transcriptions.

### 🧠 Step 3: Intelligent Data Extraction

Natural Language Processing (NLP) techniques analyze the transcription to identify key topics, features, and action items discussed during the demo.

### 🖼️ Step 4: HTML Microsite Generation

Based on the extracted data, the system generates a personalized HTML microsite. This microsite includes:

- **Summarized Key Points**: Highlighting the main features and benefits discussed.
- **Interactive Elements**: Embedding relevant videos, images, and call-to-action buttons.
- **Personalized Content**: Tailoring the microsite to address the specific needs and interests of the prospect.

### 📤 Step 5: Seamless Sharing

The generated microsite can be easily shared with prospects via a unique link, email, or embedded directly into CRM platforms.

# Key Features

- **Automated Workflow**: From transcription to microsite generation, the entire process is automated, reducing manual effort.
- **Personalization at Scale**: Tailor content for each prospect without additional workload.
- **Interactive Content**: Engage prospects with dynamic and interactive microsites.
- **CRM Integration**: Seamlessly integrate with popular CRM platforms for streamlined operations.
- **Analytics and Insights**: Track prospect engagement to refine follow-up strategies.

# Technologies Used

- **Frontend**: React.js for building dynamic user interfaces.
- **Package Manager**: pnpm for efficient dependency management.
- **Backend**: Node.js with Express.js for handling API requests.
- **Transcription**: Integration with AI-powered transcription services.
- **NLP**: Utilizing NLP libraries for data extraction and analysis.
- **Database**: MongoDB for storing user data and microsite content.
