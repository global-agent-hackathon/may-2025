# Ramso: Instant Visual Explainers

Transform complex concepts into beautiful 2-minute educational videos styled like 3Blue1Brown content. Simply enter what you want to understand, and Ramso automatically generates professional mathematical animations with voiceover—no additional inputs required.

## 🎯 Project Goal

To democratize complex knowledge through a one-click solution that turns curiosity into immediate visual understanding. Ramso aims to make advanced educational content instantly accessible to anyone with a question.

## ✨ Features

- 🤖 **AI-Powered Script Generation** - Creates educational narratives optimized for visual learning
- 🎨 **Mathematical Animations** - Generates Manim code for beautiful visualizations
- 🎙️ **Professional Voiceover** - Uses Neets AI for high-quality narration
- ⚡ **One-Click Generation** - Complete video production with zero user intervention
- 📱 **Instant Download** - Ready-to-share MP4 videos
- 🎬 **3Blue1Brown Style** - Professional mathematical animation aesthetics

## 🏗️ Architecture

Ramso uses a multi-agent system powered by Agno:

1. **Script Generator Agent** (OpenAI GPT-4o) - Analyzes concepts and creates structured video scripts
2. **Manim Code Generator Agent** (GPT-4) - Converts scripts to Manim animation code
3. **Video Generator Pipeline** - Orchestrates the complete production process

## 🛠️ Setup Instructions

### Prerequisites

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd ramso
   ```

2. **Install system dependencies (required for Manim and Python packages)**
   
   **On macOS:**
   ```bash
   brew install pkg-config cairo pango libffi
   ```
   **On Ubuntu/Debian:**
   ```bash
   sudo apt update
   sudo apt install pkg-config libcairo2-dev libpango1.0-dev libffi-dev
   ```
   **On Windows:**
   - Download and install the following:
     - [GTK 3 All-in-one bundle](https://github.com/tschoonj/GTK-for-Windows-Runtime-Environment-Installer/releases) (includes cairo, pango, and dependencies)
     - [FFmpeg for Windows](https://ffmpeg.org/download.html)
   - Add the `bin` folders of these installations to your PATH environment variable.
   - For `pkg-config`, you may need to install [MSYS2](https://www.msys2.org/) and run:
     ```bash
     pacman -S pkg-config
     ```
   - Restart your terminal after updating PATH.

3. **Set up a Python virtual environment (recommended)**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # On macOS/Linux
   # On Windows:
   # venv\Scripts\activate
   ```

4. **Install Python dependencies**
   ```bash
   pip install -r requirements.txt
   ```
   
   If you see an error about `sqlalchemy` not being installed, run:
   ```bash
   pip install sqlalchemy
   ```

5. **Install Manim**
   ```bash
   pip install manim
   ```

6. **Install FFmpeg** (if not already installed)
   ```bash
   # macOS
   brew install ffmpeg
   
   # Ubuntu/Debian
   sudo apt install ffmpeg
   
   # Windows
   # Download from https://ffmpeg.org/download.html
   ```

7. **Set up environment variables**
   ```bash
   cp .env.example .env
   ```
   Edit `.env` and add your API keys:
   ```
   OPENAI_API_KEY=your_openai_api_key_here
   ```

### Getting API Keys

1. **OpenAI API Key**
   - Visit [OpenAI Platform](https://platform.openai.com/)
   - Create an account and generate an API key
   - Add billing information for usage

## 🚀 Usage

1. **Start the Streamlit app**
   ```bash
   streamlit run app.py
   ```

2. **Open your browser** to `http://localhost:8501`

3. **Enter a concept** you want to understand (e.g., "how encryption works")

4. **Click "Generate Video"** and wait for the magic to happen!

5. **Download and share** your educational video

## 🎬 How It Works

### User Flow
1. User enters a concept they want to understand
2. System processes and generates a ~2-minute explainer video
3. User views and can download/share the finished video

### Technical Pipeline
1. **Concept Analysis** - Script agent analyzes the user's query
2. **Script Generation** - Creates structured educational narrative
3. **Animation Planning** - Converts script to Manim code specifications
4. **Voiceover Generation** - Uses Neets AI for professional narration
5. **Video Rendering** - Manim renders mathematical animations
6. **Final Assembly** - FFmpeg combines audio and video

## 🎨 Customization

### Modifying Agents

Edit `agents.py` to customize:
- Script generation style and structure
- Animation preferences and visual design
- Educational level and complexity

### Changing Models

Update the model configurations in `agents.py`:
```python
# Use different models
script_agent = Agent(model=OpenAIChat(id="gpt-4o"))
manim_agent = Agent(model=Claude(id="claude-3-5-sonnet-20241022"))
```

### Video Quality Settings

Modify `video_generator.py` to change:
- Manim rendering quality (`-pql` to `-pqh` for high quality)
- Audio settings and voice selection
- Video resolution and format

## 🔧 Troubleshooting

### Common Issues

1. **Manim not found**
   - Ensure Manim is properly installed: `manim --version`
   - Check PATH environment variable

2. **FFmpeg not found**
   - Install FFmpeg and ensure it's in PATH
   - Test with: `ffmpeg -version`

3. **API Key errors**
   - Verify all API keys are correctly set in `.env`
   - Check API key permissions and billing status

4. **Video rendering fails**
   - Check Manim installation and dependencies
   - Verify output directory permissions
   - Review generated Manim code for syntax errors

### Performance Tips

- Use lower quality settings (`-pql`) for faster development
- Consider using local models for script generation
- Implement caching for repeated concepts
